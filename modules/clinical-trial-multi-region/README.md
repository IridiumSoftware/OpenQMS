# Clinical Trial Multi-Region — Open QMS cross-overlay

**Cross-overlay.** Binds pharma + privacy + hipaa + digital-health-multi-region for sponsors + CROs running multi-region clinical trials. Encodes ICH E6(R3) GCP + per-region clinical-trial regulations + privacy framework coordination.

## Scope

Pharmaceutical + biotech sponsors + CROs operating clinical trials across US + EU + UK + Switzerland + Canada + Japan + Australia.

## Standards covered

7 clauses across ICH E6(R3) GCP + EU CTR 536/2014 + CTIS portal + 21 CFR 312 IND + DCT considerations + multi-region PHI coordination + IRB/IEC coordination + Risk-Based Monitoring + pharmacovigilance multi-region.

## Composition

Most natural: `pharma + privacy + hipaa + clinical-trial-multi-region`. Often pairs with `pharma-clinical-stage` (clinical-stage class overlay), `pharma-biologics` (if biologic), `atmp` (if ATMP), `digital-health-multi-region` (for DCT digital-platform layer), `us-state-privacy` (US state-by-state privacy).

## When to use

- Multi-region pharmaceutical clinical trials
- ATMP cell/gene therapy trials with multi-site collection + manufacturing
- DCT (decentralised clinical trial) sponsors + CROs
- IIT (investigator-initiated trial) coordination
- Pediatric trial multi-region submissions
