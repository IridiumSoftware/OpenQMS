# HITRUST i1 Intermediate — Open QMS sub-overlay

Sub-overlay on the `hitrust-csf` cross-cutting overlay. **HITRUST i1 (Intermediate) 1-year assessment** — 182 controls representing leading cybersecurity practices.

## Composition

`hitrust-csf + hitrust-i1`. Mutually exclusive with hitrust-e1 / hitrust-r2.

## When to use

- Mid-market healthcare-tech with growing PHI footprint
- SaaS providers serving healthcare payers + providers
- Vendors needing stronger-than-e1 assurance + lower-than-r2 commitment

## When NOT to use

- Lighter cyber-hygiene baseline sufficient → `hitrust-e1`
- Large PHI processors / enterprise customers requiring r2 → `hitrust-r2`
