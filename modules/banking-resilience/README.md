# Banking Resilience — Open QMS cross-overlay

**Cross-overlay.** Binds iso-37301-financial-services + dora + nist-csf + iso-22301 + FFIEC IT Handbook to encode financial-services operational + cyber resilience framework coordinated across EU DORA + US FFIEC + global NIST CSF.

## Scope

Banks + insurance + fintech + payment processors + investment firms operating multi-jurisdiction with combined EU + US + UK + Singapore regulatory exposure.

## Standards covered

7 clauses across DORA + FFIEC IT Handbook + 36-hour CSI rule + NYDFS Part 500 + TIBER-EU + CBEST + Singapore MAS AASE + Hong Kong iCAST + OCC Third-Party Risk + SR Letters + FFIEC TPRM + ISO 22301 BCM + NIST CSF 2.0 backbone.

## Composition

Most natural: `iso-37301 + iso-37301-financial-services + dora + dora-non-ctpp + nist-csf + nist-csf-tier-3 + iso-22301 + banking-resilience`. Add `dora-ctpp` if CTPP-designated. Add `iso-27001 + iso-27001-cloud + iso-27001-privacy` for IS + cloud + privacy certification. Add `pci-dss + pci-dss-saq-d-merchant` if card-payment scope.

## When to use

- Multi-jurisdiction banks (US-EU presence common)
- Significant financial entities subject to DORA TLPT
- US FFIEC-regulated banks + holding companies
- Insurance + insurance technology with multi-jurisdiction exposure
- Investment firms with multi-region authorisation
