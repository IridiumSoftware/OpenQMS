# Food-Pharma-Grade Materials — Open QMS cross-overlay

**Cross-overlay.** Binds chemicals + food-safety + pharma verticals to encode the regulatory framework for materials that come into contact with food OR pharmaceutical products.

## Scope

Manufacturers of materials at the intersection of three regulatory regimes:
- **US FCS/FCN** — 21 CFR 174-178 + FCN program per 21 USC §348(h)
- **EU FCM** — Regulation 1935/2004 framework + Regulation 10/2011 plastic FCM positive list + SMLs
- **USP pharma packaging** — <660> glass + <661> plastics + <87>/<88> biological reactivity

Typical adopter: chemical company producing polymers for food-pack converters AND for pharma container manufacturers — needs unified compliance posture across both downstream use streams.

## Standards covered

6 clauses across 4 standards (3 PUBLIC + 1 commercial USP).

## Composition

Most natural composition: `chemicals + food-safety + pharma + food-pharma-grade`. May simplify to `chemicals + food-pharma-grade` for material-supplier-only scope where downstream food-safety + pharma operations aren't in-scope of the same QMS.

Often pairs with:
- `chemicals-svhc` (REACH SVHC tracking for additives + processing aids)
- `chemicals-tonnage-10` or higher (REACH Annex I CSR for ≥10 t/y substances)
- `iso-9001` baseline manufacturing quality

## Module shape

This is a **cross-overlay** — binds across multiple verticals + encodes their intersection-specific regulatory requirements (FCN preparation + EU DoC issuance + USP biological reactivity + E&L workflows).

## Key adopter decisions

1. **Regulatory pathway selection** per food-contact substance: GRAS / prior-sanctioned / Part 174-178 / TOR exemption / FCN
2. **EU positive list verification** for plastic FCM additives + monomers + processing aids
3. **USP Class** (typically VI for direct drug contact / implantable; Class I for less rigorous)
4. **E&L study scope** per dosage form (OINDP + parenteral highest scrutiny; oral solid lowest)
5. **DoC cascade design** per EU Article 16 supply-chain documentation flow

## When to use

- Polymer manufacturer producing food-pack + pharma-pack grades
- Adhesives/coatings/sealants supplier with food + pharma contact uses
- Packaging converter operating both food + pharma contract lines
- Pharma primary packaging manufacturer with food-grade adjacent product line

## When NOT to use

- Pure non-food / non-pharma chemical manufacturer → `chemicals` alone
- Food converter using only pre-validated FCM raw materials → `food-safety` alone (suppliers handle FCM compliance)
- Pharma site using only pre-validated USP-grade packaging → `pharma` alone (suppliers handle packaging compliance)

## Forward work

- ECHA Substance Information Exchange Forum (SIEF) coordination template for shared dossier monomers
- FCN submission package template per FDA Center for Food Safety + Applied Nutrition
- EU Declaration of Compliance per stage template (raw-material / polymer / film / converter / brand-owner)
- USP <87>/<88> Class VI testing protocol template
- E&L study protocol templates per dosage form (OINDP / parenteral / oral / topical)
- DoC chain-of-compliance traceability matrix template
