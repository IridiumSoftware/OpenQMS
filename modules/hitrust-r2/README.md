# HITRUST r2 Risk-based 2-year — Open QMS sub-overlay

Sub-overlay on the `hitrust-csf` cross-cutting overlay. **HITRUST r2 (Risk-based 2-year) Validated Assessment** — 200-2000+ controls scoped by organisation factors. The gold-standard HITRUST attestation.

## Composition

`hitrust-csf + hitrust-r2`. Mutually exclusive with hitrust-e1 / hitrust-i1.

## When to use

- Large healthcare payers + providers + HIEs
- Large healthcare-tech vendors serving them
- Biopharma + life-sciences with significant PHI processing
- Enterprise vendor-management programs requiring r2 as de-facto gold standard

## When NOT to use

- Smaller scope sufficient → `hitrust-e1` or `hitrust-i1`

## 2-year cycle with interim

VAR valid 2 years; 1-year-mark interim verifies continued compliance. Material gaps at interim may trigger re-validation.

## Multi-framework crosswalk

r2 provides single-assessment crosswalk covering HIPAA + HITECH + ISO 27001 + NIST SP 800-53 + NIST CSF + PCI DSS + GDPR + state privacy laws. Primary value proposition.
