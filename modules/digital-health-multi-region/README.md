# Digital Health Multi-Region — Open QMS cross-overlay

**Cross-overlay.** Binds medical-devices + privacy + regulated-ai for digital health solutions operating across multiple jurisdictions (US + EU + UK + Switzerland + Canada + others).

## Scope

SaaS digital health platforms; telemedicine; clinical decision support; patient apps; remote patient monitoring operating multi-region.

## Standards covered

7 clauses across per-jurisdiction regulatory-scope determination + data residency + localisation (EU GDPR + China PIPL + Russia 152-FZ + India DPDP) + multi-region consent frameworks (GDPR + HIPAA + state laws + Quebec Law 25 + Ontario PHIPA) + multi-region AI/ML coordination (EU AI Act + FDA AI/ML Action Plan + Canada AIDA + UK AI principles) + multi-stream breach notification (HIPAA + GDPR + state AG + MDR §92 + FDA §524B) + ISO 13485 + MDSAP harmonisation + per-jurisdiction vigilance reporting.

## Composition

Most natural: `medical-devices + privacy + regulated-ai + digital-health-multi-region`. Often also: `hipaa` (US PHI scope), `mdr-class-iia` + `fda-class-ii` (per-jurisdiction class overlays), `connected-medical-device` (if cloud-connected + AI/ML).

## When to use

- Digital health SaaS operating in ≥2 jurisdictions
- Telemedicine platforms with cross-border patient base
- Clinical decision support deployed multi-region
- Patient apps with multi-jurisdictional user base
- ISO 13485 + MDSAP-pursuing manufacturers
