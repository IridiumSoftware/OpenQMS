# ISO 37301 Public Sector profile — Open QMS sub-overlay

Sub-overlay on the `iso-37301` cross-cutting overlay. **Public-sector compliance management profile** — community practice for government + public-administration adoption. ISO 37301 itself does not formally define sectoral tiers.

## Composition

`iso-37301 + iso-37301-public-sector`. Often paired with `iso-37001` due to elevated public-sector anti-corruption obligations under UN Convention against Corruption + OECD Anti-Bribery Convention.

## When to use

- Government agencies + public administration
- Quasi-public bodies (utilities, transit, public universities)
- Public-procurement-dependent contractors needing aligned compliance posture
