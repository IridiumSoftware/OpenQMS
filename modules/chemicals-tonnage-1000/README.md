# REACH Tonnage Band ≥1000 t/y — Open QMS chemicals class overlay

Chemicals class overlay encoding **REACH Annex X** incremental data at ≥1000 t/y per manufacturer/importer.

## Clauses

- Annex X incremental (chronic 12-month repeated dose; carcinogenicity 2-year rodent OECD TG 451 unless mechanistic waiver; EOGRTS OECD TG 443 with full Cohort 1A/1B/2A/2B/3; developmental in a second species; toxicokinetics full; sediment + soil chronic ecotox; chronic fish additional species; sediment-water + soil-organism bioaccumulation if highly bioaccumulative; degradation-product fate studies)
- Article 40 vertebrate test proposals mandatory
- Article 66 reminder — high tonnage does NOT escape Authorisation regime; rather increases Article 58 prioritisation vulnerability for Annex XIV migration

## Composition

`chemicals + chemicals-tonnage-1000`. Supersedes-and-includes all lower tonnage overlays.

## Adopter-cost note

Top tonnage tier is the most expensive registration tier:
- 2-year carcinogenicity bioassay: €1.5-3M per substance
- EOGRTS with full Cohorts: €1-2M per substance
- Chronic 12-month RDT: €300-700k per substance
- Multi-species + multi-generation ecotox: €200-500k per substance
- Full vertebrate test-proposal regulatory process: 3-5 year timeline pre-study
- SIEF joint submission essentially mandatory — no single registrant absorbs full cost
