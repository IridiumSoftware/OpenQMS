# Utility Cybersecurity — Open QMS cross-overlay

**Cross-overlay.** Binds manufacturing + iso-27001 + nist-csf for critical-infrastructure utility operators — electric (NERC CIP), pipeline (TSA SDs), water (CISA + EPA), transportation (TSA), telecom (FCC). Encodes US + EU critical-infrastructure cybersecurity framework.

## Scope

Critical-infrastructure utility operators across US + EU jurisdictions. CISA 16-sector designation applies in US; EU NIS2 essential/important entities applies in EU.

## Standards covered

7 clauses across NERC CIP-002 through CIP-014 + TSA Pipeline Security Directives + CISA 16 Critical Infrastructure Sectors + EU NIS2 + IEC 62443 OT/IT segregation + CIRCIA incident reporting + NIST CSF backbone.

## Composition

Most natural: `manufacturing + iso-27001 + nist-csf + nist-csf-tier-3 + utility-cybersecurity`. Add `iso-27001-cloud` if cloud-resident SCADA / EMS / DMS. Add `iso-22301` for ICT business continuity. Add `defense-cui + cmmc + cmmc-level-2` if DoD critical-infrastructure scope.

## When to use

- Electric utility operators (BES Cyber Systems)
- Pipeline operators (oil + natural gas)
- Water + wastewater utilities
- Transportation infrastructure operators
- Critical manufacturing
- EU operations triggering NIS2 essential/important entity designation
