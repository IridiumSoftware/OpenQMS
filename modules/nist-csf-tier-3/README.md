# NIST CSF Tier 3 (Repeatable) — Open QMS sub-overlay

Sub-overlay on the `nist-csf` cross-cutting overlay. **NIST CSF v2.0 Implementation Tier 3 — Repeatable** per §3.4.

Formally-approved organisation-wide policy. Risk-informed processes consistently applied. Active external participation.

## Composition

`nist-csf + nist-csf-tier-3`. Mutually exclusive with other tier sub-overlays.

## When to use

- Established mid-market + enterprise organisations with mature cybersecurity
- Regulated industries (financial services, healthcare, defense) where Tier 3 is a baseline regulatory expectation
- Most-common TARGET state for well-resourced cybersecurity programs
