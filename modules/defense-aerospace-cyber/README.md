# Defense Aerospace Cyber — Open QMS cross-overlay

**Cross-overlay.** Binds aerospace + aerospace-defense + defense-cui + cmmc + cmmc-level-2 to encode the DoD aerospace cybersecurity regulatory intersection.

## Scope

Defense aerospace prime contractors + sub-contractors handling Controlled Unclassified Information (CUI) + Covered Defense Information (CDI) + ITAR-controlled technical data + operating airworthiness-certified systems with cybersecurity requirements.

## Standards covered

7 clauses across DFARS 7012/7019/7020/7021 stack + MIL-STD-882E joint safety+cyber + ITAR USML Category VIII + airworthiness cybersecurity (DO-326A/DO-356A/DO-355/ED-202A) + NIST SP 800-161 supply chain risk management + DoDI 5000.90 platform cyber resilience + CMMC Level 2 binding.

## Composition

Most natural: `aerospace + aerospace-defense + defense-cui + cmmc + cmmc-level-2 + defense-aerospace-cyber`. May elevate to `cmmc-level-3` for NS-critical contracts. Compose with `aerospace-dal-a` or `dal-b` for safety-critical joint cyber + DAL assessment.

## When to use

- DoD aerospace primes (Boeing, Lockheed, Northrop, Raytheon scale + tier-1 + tier-2 suppliers)
- ITAR-registered aerospace manufacturers
- Foreign Military Sales (FMS) participants
- Airworthiness-certified-system manufacturers serving DoD
- DARPA / SBIR / OTA / FAR Part 12 awardees handling CUI

Reuses parent-overlay templates with binding deltas — no new templates.
