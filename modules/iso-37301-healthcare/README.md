# ISO 37301 Healthcare profile — Open QMS sub-overlay

Sub-overlay on the `iso-37301` cross-cutting overlay. **Healthcare-sector compliance management profile**.

## Composition

`iso-37301 + iso-37301-healthcare`. Often paired with `privacy` (for HIPAA-adjacent state laws) and may compose with `pharma` (for industry-sponsored research) or `medical-devices` (for connected-device offerings).

## When to use

- Hospitals + integrated delivery networks
- Health plans / payers
- Healthcare-tech vendors subject to BAAs
- Academic medical centers with research compliance scope
- 340B covered entities + hospitals with pharmacy operations
