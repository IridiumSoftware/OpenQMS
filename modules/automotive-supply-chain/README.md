# Automotive Supply Chain — Open QMS cross-overlay

**Cross-overlay.** Binds automotive + ISO 26262 + ISO/SAE 21434 + recall-workflow to encode end-to-end automotive supply-chain regulatory framework — OEM-to-tier-N coordination of functional safety + cybersecurity + recall + supplier qualification.

## Scope

Automotive OEMs + tier-1 + tier-2 suppliers + software suppliers (OTA platforms, ADAS perception, AD stacks) + semiconductor + ECU + actuator suppliers.

## Standards covered

7 clauses across ISO 26262-8 DIA + IATF 16949 + AIAG PPAP + ISO/SAE 21434 cybersecurity supplier management + UN R155 Type Approval CSMS + UN R156 SUMS + NHTSA Part 573 recall coordination + tier-N flow-down + software-supplier special considerations.

## Composition

Most natural: `automotive + automotive-asil-d + automotive-cal-4 + recall-workflow + automotive-supply-chain`. Add `defense-aerospace-cyber + defense-cui + cmmc + cmmc-level-2` for defense automotive (military vehicle programs). Add `iso-27001` for IT-security baseline.

## When to use

- Automotive OEMs managing tier-1 + tier-2 supplier programs
- Tier-1 suppliers serving multiple OEMs
- Software-only suppliers (AD stacks, OTA platforms, ADAS perception)
- Semiconductor suppliers to automotive (Tier-2 ECU components)
- ATS / engineering-services contractors with PPAP scope
