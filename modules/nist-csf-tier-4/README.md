# NIST CSF Tier 4 (Adaptive) — Open QMS sub-overlay

Sub-overlay on the `nist-csf` cross-cutting overlay. **NIST CSF v2.0 Implementation Tier 4 — Adaptive** per §3.4.

Continuous adaptation based on lessons learned + predictive indicators. Bidirectional real-time ecosystem information sharing. Culture-level risk management.

## Composition

`nist-csf + nist-csf-tier-4`. Mutually exclusive with other tier sub-overlays.

## When to use

- Large financial institutions
- Cloud hyperscalers
- Cybersecurity vendors themselves
- IC + DoD high-end elements
- Stretch goal for ambitious mid-market security programs

## When NOT to use

- Most adopters should target Tier 3 — Tier 4 requires continuous-monitoring + automated-response maturity beyond most resource envelopes
