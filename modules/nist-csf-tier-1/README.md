# NIST CSF Tier 1 (Partial) — Open QMS sub-overlay

Sub-overlay on the `nist-csf` cross-cutting overlay. **NIST CSF v2.0 Implementation Tier 1 — Partial** per §3.4.

## Scope

Organisations whose cybersecurity risk management is ad hoc + reactive, with limited organisational awareness and no external participation.

## Standards covered

4 clauses across the 3 Implementation Tier attributes (Risk Management Process / Integrated Risk Management Program / External Participation) + typical-adopter framing.

## When to use

- Very small businesses with limited cyber dependency
- Startups pre-security-investment
- Documenting current-state baseline before maturity growth (most common use)

## When NOT to use as TARGET state

Tier 1 is rarely a target. Most organisations should aim Tier 2+ over time. Document Tier 1 as current state, then plan Tier 2 transition.

## Composition

`nist-csf + nist-csf-tier-1`. Mutually exclusive with higher-tier sub-overlays for a given assessment cycle (Implementation Tiers describe one organisational maturity level at a time).
