# REACH Tonnage Band ≥1 t/y — Open QMS chemicals class overlay

Chemicals class overlay encoding **REACH Annex VII baseline** data requirements at ≥1 t/y per manufacturer/importer.

This is the entry-tier overlay. Use it when registering at the 1-10 t/y band where Annex VII applies but Annex VIII (CSR) does not yet trigger.

## Clauses

- Annex VII baseline (Physico-Chemical + Toxicological screening + Ecotoxicological screening)
- Article 12(1)(b) Registration content 1-10 t/y range
- Annex XI data waiving

## Composition

`chemicals + chemicals-tonnage-1`. Step up to `chemicals-tonnage-10` once production volume exceeds 10 t/y per registrant.

## Adopter-cost note

At 1-10 t/y, registration is technically lighter — no CSR mandated — but **Annex VII vertebrate-testing requirements** (skin sensitisation in vivo OR LLNA; acute oral toxicity) still drive ~€50-150k typical compliance cost per substance. Joint submission via SIEF reduces per-registrant share.
