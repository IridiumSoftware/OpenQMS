# NIST CSF Tier 2 (Risk Informed) — Open QMS sub-overlay

Sub-overlay on the `nist-csf` cross-cutting overlay. **NIST CSF v2.0 Implementation Tier 2 — Risk Informed** per §3.4.

Risk management practices management-approved but not organisation-wide policy. Awareness exists but lacks integration. Selective external participation.

## Composition

`nist-csf + nist-csf-tier-2`. Mutually exclusive with other tier sub-overlays.

## When to use

- Small-to-medium businesses with growing cyber awareness
- First-year / second-year cybersecurity-program adopters
- Transitional state between Tier 1 ad-hoc and Tier 3 organisation-wide policy
