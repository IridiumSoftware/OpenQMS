# PER-XXX: [Product Name] Performance Evaluation Report (IVDR)

Per EU IVDR 2017/746 Annex XIII. The Performance Evaluation Report (PER) is the IVD equivalent of the medical device CER (Clinical Evaluation Report). It synthesizes evidence across three pillars: **scientific validity**, **analytical performance**, **clinical performance**. The PER is mandatory for all IVDs and updated throughout the device lifecycle per Article 56 cadence.

**Per-class customization.** Class A IVDs typically rely on literature + manufacturer experience; Class B/C add structured analytical performance studies; Class D adds rigorous clinical performance studies (often interventional) and is subject to expert panel + reference lab consultation under IVDR.
