# GLP-XXX: GLP Study Plan + Final Report for [Test Item]

Per **OECD Principles of Good Laboratory Practice** (ENV/MC/CHEM(98)17; revised 1997; OECD Series on Principles of GLP and Compliance Monitoring No. 1). GLP applies to non-clinical safety studies on test items contained in pharmaceutical products, pesticide products, cosmetic products, veterinary drugs, food additives, feed additives, **and industrial chemicals** (the focus when this template is composed with the chemicals vertical).

GLP is **not** a quality system for analytical methods or QC testing — it specifically covers non-clinical health-and-environmental safety studies. The principles ensure data integrity + reproducibility + reconstructability of study outcomes for regulatory submission.

This template combines the **Study Plan** (per Principle 8.1; written before study initiation) and the **Final Report** (per Principle 9.1; written after study completion). Multi-section structure; sections marked [PRE] are completed before study start; sections marked [POST] are completed at study end.

## 1. Identification of the study [PRE]

- **Title:** [descriptive title]
- **Test item identification:** chemical identity + CAS # + lot/batch # + purity + stability under storage conditions + amount available
- **Reference item:** if applicable (e.g., positive control)
- **Test system:** species/strain (if biological) OR matrix (if physico-chemical) + supplier + age + sex + body weight range + acclimatisation period
- **Sponsor:** name + address + contact
- **Test facility:** name + GLP-monitoring-authority registration + address + GLP compliance statement
- **Study Director:** [name + qualifications + facility role]
- **Principal Investigator(s)** (multi-site studies): [name + site + responsibility scope]

## 2. Quality Assurance Programme statement [PRE + ONGOING]

Per Principle 2.2. QA Programme:
- Independent of study conduct
- Carries out inspections (per study + per facility + per process) to ensure compliance with GLP + the Study Plan + SOPs
- Maintains written audit reports; reports findings to Study Director + Test Facility Management
- QA verifies the Final Report reflects the raw data accurately

| Inspection type | Date | Inspector | Findings | Resolution |
|---|---|---|---|---|

## 3. Test + reference item [PRE]

- **Test item characterisation:** identity + concentration + purity + stability (under storage AND test conditions); analytical method for characterisation; impurity profile; container + storage
- **Reference item:** same characterisation as test item
- **Receipt + storage records:** chain of custody from sponsor / supplier to test facility
- **Disposition of remaining test item:** per Principle 6 (retain or return per Sponsor agreement)

## 4. Test system [PRE]

For animal studies: species + strain + supplier + age + sex + body weight range + acclimatisation + housing + diet + water + environmental conditions + group identification + randomisation procedure.

For non-animal systems: matrix description + analytical instrumentation + reference standards.

Examples: SOP for randomisation; SOP for clinical observations; SOP for blood collection; SOP for analytical method [X]; SOP for archiving; SOP for handling of test items.

## 7. Performance of the study (per Principle 8) [ONGOING]

Raw data captured:
- Directly + promptly + legibly + signed/initialled + dated
- Permanent + indelible
- Changes corrected without obscuring previous entry (single-line strikethrough with date + initial + reason)
- Electronic raw data with audit trail per 21 CFR Part 11-equivalent integrity

Deviations from Study Plan + SOPs documented in raw data with reason + impact assessment.

## 10. Archive (per Principle 9.2)

- Study Plan + amendments
- All raw data
- Specimens + samples
- Final Report
- QA inspection records
- SOPs at versions used during study
- Personnel records relevant to the study
- Environmental records

Archive minimum 10 years post-study (longer if Sponsor + regulator require). Indexed for retrievability. Access controlled. Disaster recovery (off-site backup or fire-resistant storage).
