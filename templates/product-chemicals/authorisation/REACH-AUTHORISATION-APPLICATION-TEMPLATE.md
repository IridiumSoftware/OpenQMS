# REACH Authorisation Application (Article 62)

**Template for:** REACH Title VII Authorisation application per Article 62 for a substance listed on Annex XIV.
**Submission:** Via REACH-IT to ECHA. ECHA fee per Article 73(2) Commission Regulation (EC) 340/2008 applies (varies by enterprise size + substance/uses count).
**Deadline:** Latest application date (LAD) = 18 months before sunset date. After LAD, applications still accepted but no automatic continuation of use post-sunset.

**Adequate Control route NOT available for:**
- Non-threshold CMR (Article 57(a) Category 1A/1B with no threshold per Annex I §6.4)
- PBT (Article 57(d))
- vPvB (Article 57(e))
- Equivalent-level-of-concern (Article 57(f)) substances for which no threshold can be determined

For these, Socio-Economic route is mandatory.

## 7. Socio-Economic Analysis (SEA) — Article 62(5)(a) + Annex XVI

Required if Socio-Economic Route. Recommended supplementary even on Adequate Control route to support continued use case.

| Annex XVI Element | Content |
|---|---|
| Identification of impacts | Health, environmental, economic, social — quantified where possible |
| Boundaries of analysis (geographic + temporal) | |
| Benefits of continued use (use applied for) | Producer surplus + consumer surplus + downstream value-chain impact |
| Risks of continued use (residual after RMM) | Quantitative if possible; qualitative if not |
| Comparison to non-use baseline | What happens if authorisation NOT granted (substitution forced / use discontinued / off-EU production) |
| Sensitivity analysis | Key parameters varied |
| Distributional analysis | Who bears costs vs. benefits |
| Conclusions | Net benefit calculation |
