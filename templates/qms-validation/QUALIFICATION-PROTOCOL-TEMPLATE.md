# VAL-QUAL-[SYSTEM]-001: Qualification Protocol for [System name]

The **robust-scripted** qualification path for a computerized system under EU GMP Annex 15 — design, installation, operational, and performance qualification under the [Validation Master Plan](VALIDATION-MASTER-PLAN-TEMPLATE.md). Each executed stage produces an [Assurance Record](ASSURANCE-RECORD-TEMPLATE.md) (`VREC`, robust-scripted tier).

> Apply the stages **proportionate to risk** (Annex 11 §1 / ICH Q9). A low-risk system may not warrant all four stages — record the rationale in the [Assurance Determination](ASSURANCE-DETERMINATION-TEMPLATE.md).

## 1. Design Qualification (DQ)

[Documented verification that the proposed design is suitable for the intended use — requirements from the URS, supplier assessment, GAMP category, and design specifications.]

## 2. Installation Qualification (IQ)

[Documented verification that the system as installed conforms to the approved design — versions, configuration, environment, supporting utilities/infrastructure.]

## 3. Operational Qualification (OQ)

[Documented verification, via scripted test cases with expected results, that the system operates as intended across its operating range — including challenge/boundary and security/access checks.]

## 4. Performance Qualification (PQ)

[Documented verification that the system performs reproducibly in the production/QMS process under real or simulated conditions — typically using production data and process workflows.]

## 5. Acceptance and approval

[Summary of results per stage, deviations + resolutions, conclusion of acceptability for intended use, and signatory approval before the system enters/returns to use.]
