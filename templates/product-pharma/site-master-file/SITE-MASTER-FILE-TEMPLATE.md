# SMF-XXX: Site Master File

Per EU GMP Part III + PIC/S Explanatory Notes for Pharmaceutical Manufacturers on the Preparation of a Site Master File (PE 008 series). The Site Master File (SMF) is a document prepared by the manufacturer containing specific information about the quality management policies and activities of the site and the production and/or quality control of pharmaceutical manufacturing operations carried out at the named site.

The SMF is **not** a marketing document — it is the inspector's reference document. It should provide clear information about the manufacturer's GMP-related activities to enable a regulator (or notified body / competent authority / customer auditor) to plan + execute an effective inspection.

The SMF is typically required for: EU MA holders for each manufacturing site (per EU GMP Part III); ATMPs per EU GMP Annex 2A; sites under PIC/S-aligned authorities (WHO PQ; MHRA; Health Canada; PMDA where applicable). FDA does not formally require an SMF but accepts equivalent site-overview documentation during inspections.

## 10. ATMP-specific additions (where applicable per EU GMP Annex 2A)

If the site manufactures ATMPs, the SMF includes additional sections per Annex 2A:

- **Donor / patient material handling:** procurement + traceability per Annex 2A §3 + §10 + 21 CFR 1271
- **Vector + raw material control:** characterization + release + storage of vectors + helper plasmids + packaging cells
- **Aseptic processing arrangements:** closed-system processing; isolator + RABS; APS qualification per PIC/S Annex 1 with ATMP adaptations
- **Comparability strategy for manufacturing change:** reference to ICH Q5E + Comparability Protocols (COMP-XXX)
- **Special handling for autologous products:** patient-product reconciliation; cold chain integrity from procurement through administration

## 11. Annexes

- **Annex 1:** Copy of valid manufacturing authorisation / establishment registration
- **Annex 2:** List of dosage forms / products manufactured (with strengths + classifications)
- **Annex 3:** Copy of GMP certificate (most recent)
- **Annex 4:** List of contract manufacturers + contract laboratories with reference to written agreements
- **Annex 5:** Simple site layout plan (block diagram)
- **Annex 6:** Schematic drawings of production areas with air-classification cascades
- **Annex 7:** Schematic drawings of warehousing areas
- **Annex 8:** Schematic drawings of QC laboratories
- **Annex 9:** Organisation charts (top-level + production + QC + QA)
- **Annex 10:** List of GxP-critical computerised systems (per EU GMP Annex 11)
